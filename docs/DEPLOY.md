# 运行、切换与部署边界

仅本地研发。scripts/start-local.ps1使用自身虚拟环境，默认127.0.0.1:8000提供静态H5；不使用隧道或公网。stop-local.ps1核验端口、解释器、脚本路径和进程归属，只停止本项目实例。

修改源码不会升级现有进程。先用隔离数据验证，再受控停止实例、保护runtime备份、部署匹配的静态文件并启动。S2启动执行004迁移，保留S1凭据与会话；不能为演示清空或替换真实数据库。

初始化保存后回主界面的修复已独立完成。S2实例切换、端口健康及迁移证据由阶段报告记录，不因源码完成便宣称在线实例已升级。切换使内存会话失效，刷新可重新建立，不必重新输入已保存Key。

启动/停止按端口保存PID和日志，识别Windows venv监听子进程，不重复设置已满足要求的ACL。隔离生命周期测试使用一次性合成工程，不操作正在使用的8000实例。

依赖修复历史见[安全状态](SECURITY-BLOCKERS.md)，本轮复查见[验证记录](VALIDATION.md)。旧55/7和中间14项属历史，不能继续误报为当前未修复；既有0公告也不是生产安全证明。公网身份、隔离、TLS、托管密钥和备份删除仍需独立验收。

H5开发页不处理真实Key；weapp受限产物Key入口关闭，HTTPS后端、跨端绑定和真机未验收。NCP不发送网络，商品仅官方关键词跳转。用户已授权本公开源码副本；代码AGPL-3.0-only、原创文档CC BY 4.0，公网部署仍未获授权。
