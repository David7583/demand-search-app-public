# 本机浏览器使用与一键启动

当前继续使用本地浏览器界面，不安装桌面壳，也不进行公开部署或微信发布。日常使用不需要重复安装依赖、运行 npm 或在终端输入密钥。

## 开始与停止

1. 在项目文件夹双击 **Start-Demand-Assistant.cmd（启动需求助手）**。
2. 后端在隐藏窗口中运行。确认是本项目且健康检查通过后，自动在默认浏览器打开 **http://127.0.0.1:8000**。
3. 已在运行时再次双击，会复用本项目服务并重新打开页面，不创建第二个实例。
4. 使用完毕可双击 **Stop-Demand-Assistant.cmd（停止需求助手）**。只停止身份、端口、解释器和脚本路径均符合记录的本项目服务。

关闭浏览器标签页不会停止后台服务。停止应用、再次启动或关闭浏览器不会自动删除模型配置、历史会话、数据库或导出文件。停止前先完成当前保存/AI 请求；正在处理的请求可能被中断。

两个 CMD 文件可以创建 Windows 快捷方式到桌面，快捷方式目标保留原项目中的 CMD 文件。不要只把 CMD 文件复制到桌面，它需要相邻 scripts 目录。项目路径中的空格和中文受到支持；搬迁整个已初始化工程仍应按下节重新检查虚拟环境，不共享其他工程的依赖。

## 页面操作

启动后进入原来的聊天界面。初次未配置模型时按向导操作；后续右上角“设置”可修改模型。真实 API Key 仅在同源本地页面输入，不发到聊天、日志或文档。

可以先保存原话；启用“连续 AI 理解”并确认服务商、模型和外部处理后，后续消息才会自动理解。每份清单最多30项；先检查整份清单，再确认。官方搜索入口只发送你确认的关键词，不提供商品 API 数据、真实价格或自动比价。

刷新或后台重启后可能需要重新建立本地页面会话，但已保存的模型配置和历史保留。若页面长时间未更新，可重新打开入口或刷新浏览器；不要通过清空数据库解决界面问题。

## 连续讨论与恢复

顶部可在“AI 对话”和“方案工作区”之间切换，宽屏可选择并排协作，侧栏可折叠。历史回复下的“查看方案与版本”会定位到该回复对应的版本；有未保存编辑或操作进行中时，先处理当前内容再切换版本。

输入框有尚未发送的文字时，新建或切换会话会要求选择“继续编辑”或“确认离开”。取消保持文字、当前会话及授权状态；离开不会替你保存或调用 AI。未发送文字只在页面内存中，刷新或关闭浏览器前应先发送保存或自行保留。

若聊天页提示方案读取失败，可点击“重新读取方案（不调用 AI）”。该按钮只重新读取本地版本；成功后可以主动生成回复，不自动补发模型请求。停止回复或网络中断后，也应先在工作区刷新版本，再决定是否重新生成。

历史方案仍是只读快照。通过方案页的讨论/反馈入口或历史回复的“提出修改”，输入框会附上所引用的版本；发送前可以移除引用。有不同引用时先移除原引用，再选择另一版本。保存后引用随消息保留，刷新重开会话仍有效。

授权生成时，模型会收到该条消息明确引用的版本详情、最新草稿、确认版及有限近期原话；只在文字中自行写一个版本号不会建立引用。模型据此讨论后生成当前版本之后的新草稿，不自动回滚或采纳旧版。上下文过长会明确拒绝；可以发送一条不带引用的新消息继续。

本轮实际桌面成绩和快照状态见[验证记录](VALIDATION.md)。

## 首次初始化或缺少文件

一键入口只启动已经安装和构建好的本地应用，不联网安装、不执行全局 pip/npm 安装，不自动升级依赖。首次准备由开发者在项目根执行：

```powershell
# 必须是 CPython 3.12.7；Node 24.18.0、npm 11.16.0。
./scripts/init.ps1 -Python python
npm.cmd --prefix apps/client run build:h5
```

之后日常双击启动入口即可。项目自己的 .venv 必须是物理目录；不能链接或借用 NCP/其他工程环境。安装与构建失败时保持原应用数据，先处理具体诊断。

CMD 入口仅为这次 PowerShell 进程指定 RemoteSigned 策略，不修改系统或用户的永久执行策略。组织策略或下载文件标记仍可能阻止脚本；先核对文件来源并联系管理者，不绕过组织限制或批量解除未知文件限制。启动失败的窗口会保留诊断，按任意键后关闭。

## 常见诊断

| 诊断 | 处理 |
|---|---|
| LOCAL_ENV_MISSING / LOCAL_ENV_INVALID | 缺少本项目 .venv 或解释器不符合要求；按初始化步骤检查，不能改用全局依赖运行。 |
| LOCAL_BUILD_MISSING | 缺少本地 H5 页面，完成一次 build:h5 后再启动。 |
| LOCAL_DEPENDENCIES_MISSING | 本项目后端依赖不完整；按固定锁重新执行 init.ps1。 |
| LOCAL_PROJECT_INCOMPLETE | 项目脚本缺失；恢复完整本地工程，不去改其他项目。 |
| LOCAL_PORT_IN_USE / Listener ownership mismatch | 8000 被未确认为本项目的进程占用；启动/停止入口不会杀掉它。先识别占用来源，不随意结束进程。 |
| LOCAL_SERVICE_UNHEALTHY | 本项目已有进程但健康检查失败；入口不会悄悄重启。先检查项目内私人错误日志，再决定停止/重启。 |
| LOCAL_BROWSER_OPEN_FAILED | 服务已经运行；手动在浏览器打开 http://127.0.0.1:8000。 |
| LOCAL_STATE_LINKED | 私人目录、日志目录或进程记录是链接；恢复本项目自己的物理目录，避免读写其他位置。 |
| LOCAL_MODE_REQUIRED / DSA_DATA_SUBDIR 提示 | 用户启动需要 local-dev 且不带测试子目录环境变量；不要把测试进程混为日常应用。 |

日志位于本项目 .local/logs，仅本机诊断使用，不上传原始日志或运行数据。日志可能帮助定位依赖和启动错误；不要将真实 Key 或私人需求复制到问题报告。

## 本地验证

```powershell
./.venv/Scripts/python.exe scripts/verify.py --stage S5 --target desktop --browser
./.venv/Scripts/python.exe scripts/smoke_launcher.py
```

生命周期检查只使用 .local 中独立的合成工程、合成健康服务、随机回环端口和临时环境；不启动/停止真实8000实例，不读取真实会话或 Key，不实际打开默认浏览器。该检查包括路径含空格/中文、重复启动、异常健康状态、他人端口拒绝和停止后数据保留。浏览器打开参数使用替代脚本验证，默认浏览器实际弹出需日常双击时观察。

本机能用不等于生产网络安全或微信真机验收通过；本公开源码副本已获授权，其余平台开发暂停。本说明不要求改变许可证决定，也不扩大已授权的本地功能范围。
